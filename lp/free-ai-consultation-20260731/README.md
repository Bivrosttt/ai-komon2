## 設計意図

ファーストビューは5本とも「AIを使いたい。まずは、いまの業務を聞かせてください。」で統一し、業種ごとの課題は「活用例」として見せています。LPでは「なぜコンサル1回分を無料にするのか」「何を見てもらえるのか」「誰が対応するのか」「コンサル後に契約が必要なのか」を説明する信頼構築型の構成にしています。

比較・一覧ページは作らず、5本を個別LPとして運用します。既存LP・既存素材は残しています。広告・計測用のクエリは、各ページのCTAから `from=free_consult_<industry>` として既存の無料AI活用診断ページへ引き継ぎます。
