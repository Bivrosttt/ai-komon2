# 5業界クリエイティブ 最終セルフレビュー

実施日: 2026-07-30

## 制作工程

1. Behanceの公開広告クリエイティブを5テーマから100枚収集・保存。
2. 100枚を一覧で確認し、構図・視線誘導・写真とコピーの関係を比較。
3. 採用した構図原則を業界固有の作業場面へ転用。
4. 画像生成でテキスト込みの正方形クリエイティブを生成。
5. 全5本を原寸で確認し、コピー・余計な文言・業界の手掛かり・画面構成をチェック。

## 最終チェック

- [x] 1秒以内に業界と具体的な困りごとの手掛かりがある
- [x] 写真だけでも、何に時間を取られているか読める
- [x] コピーが写真の中の具体物（白紙台帳、時計、図面、赤い変更票、電話と行列）を指している
- [x] メインコピー以外の説明文、CTA、無料相談、ブランド名、バッジを入れていない
- [x] 分割テンプレート、グラフ、ダッシュボード、AIロボット表現を使っていない
- [x] 5本が色違いの同じレイアウトになっていない
- [x] 5本とも1254×1254pxの正方形で統一されている
- [x] 既存版は `archive/creative-v2-before-research-20260730/` に退避済み

## 判断

今回は広告の役割を「自分の業務の詰まりに気づいて止まること」に限定した。AIの説明や相談への説得はLP側へ渡し、広告上ではそれらを説明する小さなコピーを足さない。これにより、ファーストビューの情報量を増やさず、業界固有の痛みとAI顧問の訴求をLPで接続できる状態にした。
