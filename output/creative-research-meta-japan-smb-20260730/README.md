# 日本の中小・地域サービス向け獲得広告リサーチ 100枚

## 目的

AI顧問室の広告制作に使えるよう、日本向けの中小・地域サービス広告を、認知広告ではなく問い合わせ・予約・見積・査定・応募などの獲得導線があるものに絞って確認する。

## 収集条件

- Meta広告ライブラリの国設定を日本（JP）に固定
- 工務店、リフォーム、不動産、美容、整体、歯科、学習塾、士業、採用、運送などの業種語で検索
- 広告文に予約、相談、見積、査定、資料請求、応募、体験、来店、問い合わせなどの獲得シグナルがあるものを採用
- 大手消費者ブランド、全国ブランド、比較ポータル、インフルエンサー／アンバサダー、認知・フォロー目的の投稿を除外
- 同一広告主の採用数は最大4枚に制限

## 注意

Meta広告ライブラリに掲載されていることは、広告が存在することの確認であり、CVRやCPAが高いことの証明ではない。勝ちクリエイティブではなく、「日本の獲得広告が実際にどの情報量・構図・オファーで出稿されているか」を見るための研究候補として扱う。

## 確認ページ

- `review-board.html`: 100枚の画像一覧。各画像からMeta広告ライブラリの出典へ移動できる。
- `references.json`: 広告主、検索語、掲載文、画像URL、広告ライブラリURL。
- `archive-stale/`: 途中収集時に除外した画像。納品対象には含めない。
