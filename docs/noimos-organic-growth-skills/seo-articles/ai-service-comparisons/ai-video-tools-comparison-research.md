# AI動画生成サービス比較リサーチ

取得日: 2026-07-31 / 通貨: USD

## 公式情報

| サービス | 機能・usage・価格の根拠 |
| --- | --- |
| Runway | [公式料金](https://runwayml.com/ja/pricing) はStandard $15/月（年払い表示$12）、625 credits/月。公式のcredits説明ではGen-4.5は60 credits/5秒で、Standardは約52秒相当。 |
| HeyGen | [公式料金](https://www.heygen.com/ja-jp/pricing) はCreator $29/月・600 credits・最大30分/動画・175言語以上、Pro $49/月。creditsから分数への換算式は公開されていない。 |
| Synthesia | [公式料金](https://www.synthesia.io/pricing) はStarter $29/月（年払い表示$18）、最大10分/月。125以上のアバター、Starterは編集者1名+ゲスト3名。 |
| Adobe Firefly | [公式ページ](https://www.adobe.com/products/firefly.html) はStandard $9.99/月・2,000 credits・5秒動画最大20本相当、Pro $19.99/月・4,000 credits。 |

## 判断

- 広告・SNSの短尺素材: Runway
- アバター営業・翻訳: HeyGen
- 研修・eラーニング: Synthesia
- Creative Cloud中心の制作: Firefly

単発レビューを仕様の代わりに使わず、公式価格を計算、レビューを強み弱みの説明に使った。
