## 共通の必須要素

1. 初出のサービス名を公式サイトへリンクする。
2. 料金・usage・コスパ表と、強み・弱み表を置く。
3. 公式情報と国内外レビューを分け、レビューは傾向として記述する。
4. 読者へ再調査を返す文、同一素材での実験宿題、社内承認チェックリストを本文から排除する。
5. サービス選定を、業務への実装と定着までつなぐCTAにする。
6. 各サービス節の先頭に公式ホーム画面スクリーンショットを置く。アクセス制限時は公式Docs掲載画面を明記して代替する。
