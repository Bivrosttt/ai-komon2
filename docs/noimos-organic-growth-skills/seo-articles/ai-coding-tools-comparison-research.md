# AIコーディングサービス比較リサーチ

取得日: 2026-07-31 / 通貨: USD

## 公式情報

| サービス | 機能・usage・価格の根拠 |
| --- | --- |
| GitHub Copilot | [日本語料金](https://github.com/features/copilot/plans?locale=ja) はFree 2,000補完/月、Pro $10+$15 AI credits、Pro+ $39+$70、Max $100+$200。 |
| Cursor | [料金](https://www.cursor.com/pricing) はHobby無料、Pro $20/月、Teams $40/ユーザー/月。Pro+はProの3倍、Ultraは20倍のAgent上限。含有量超過はon-demand後払い。 |
| Claude Code | [料金](https://claude.com/pricing) はPro $20/月（年払い$17）、Max $100〜でProの5倍/20倍利用。Claude CodeはProに含まれる。 |
| Replit | [料金](https://replit.com/pricing?web=1) はStarter無料、Core $25/月（年払い$20、$25 credits）、Pro $100/月（年払い$95、$100 credits）。Agentの複雑さで消費量が変わる。 |

## 判断

- GitHub内の補完・レビュー: Copilot
- IDEで複数ファイルを編集: Cursor
- 端末で調査からPRまで: Claude Code
- 環境構築なしの試作・公開: Replit
