# AI顧問室 5業界クリエイティブ探索メモ

作成日: 2026-07-30

## 方針

AIそのものを売るのではなく、各業界ですでに認識されている「終わらない仕事」「人手不足」「ベテラン依存」を入口にする。画像は1:1のMeta広告用で、1枚につき1業界・1つの痛みに絞った。

## 業界選定

中小企業基盤整備機構の2026年調査では、AI導入率は全体20.4%、建設業15.9%、不動産業・物品賃貸業18.3%、製造業16.4%、運輸業・郵便業9.7%、宿泊業・飲食サービス業18.0%。AI未導入層に届く余地と、AI顧問室の既存デモ／実装力の両方を見て5業界を選定した。

導入障壁は「導入コスト」46.9%、「社内のAIノウハウ不足」42.0%、「社内のAI人材不足」38.8%。広告では「AI導入」ではなく、具体的な1業務を伴走して整理するサービスとして伝える。

## コピー設計ルール

- 「AIで効率化」「人手不足」のような抽象語を一行目に置かず、誰が・いつ・何をしているかを描く。
- 現場の一文は `何をした後 → 何分たっても → 何が終わらないか` で書く。例：「現場写真を80枚撮った。事務所に戻って30分。写真台帳はまだ白紙。」
- クリエイティブに表示するのはメインコピーのみ。説明文、AIの機能、CTA、免責は画像の外へ出す。
- フックは、時間・中断・検索・属人化・紙作業など、現場で目に見える違いを複数案で出す。
- 数字は調査出典とセットでLPや広告本文に使う。画像の一行目では、数字よりもその場面の具体性を優先する。

### 建設

- サイボウズの2026年調査では、建設従事者の54.4%が書類作成・写真整理などの事務作業に1日2時間以上を費やし、現場管理・現場担当・監理技術者では38.7%が手書きメモ等の打ち直しを負担として回答。
- 実務事例では、現場写真をPCへ取り込み、工種・場所別にファイル名を付け、写真台帳へ貼り付け、コメントを入力し、日報をExcelへ転記する流れが確認できる。
- 国交省資料では、現場監督の周辺業務に写真整理、出来形・品質・工程管理、各種書類作成が含まれる。

コピー候補：

1. 「現場写真を80枚撮った。事務所に戻って30分。写真台帳はまだ白紙。」
2. 「17時に現場を出た。18時半、まだ日報を打っている。」
3. 「黒板入りの写真を、1枚ずつ工種別に分けている。」
4. 「電話で受けた変更指示が、どの報告書に関係するか分からない。」

根拠：[サイボウズ建設業務調査](https://topics.cybozu.co.jp/news/2026/05/27-19438.html)、[国交省・建設業の事例資料](https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/const/content/001612258.pdf)

### 不動産

- 問い合わせ後の初動速度と、その後の追客が具体的な課題。LIFULL HOME'Sは170万件の問い合わせデータをもとに初期対応・追客タイミングを扱っている。
- 小規模不動産会社調査では、追客したくてもできない理由として人手不足、設備・教育不足、営業・リード管理の標準化不足が挙がった。なお、同調査は有効回答25件と小規模なので、数字を一般化しない。
- 国交省資料では、不動産DXの導入余地として業務・手続き負担の軽減や顧客接点のデジタル化が示されている。

コピー候補：

1. 「11:02に問い合わせ。11:32、まだ返信できていない。」
2. 「接客が終わった。誰に何を返すか、もう分からない。」
3. 「内見から3日。お礼の連絡をまだ送れていない。」
4. 「『初期費用は？』物件が変わるたび、また調べ直している。」

根拠：[LIFULL HOME'S・問い合わせ追客データ](https://biz.homes.jp/download/white-paper/white-paper-know-how-00014)、[小規模不動産会社調査](https://eslab.branding-t.co.jp/2025/12/16/1-48/)、[国交省・不動産DX資料](https://www.mlit.go.jp/policy/shingikai/content/001864124.pdf)

### 製造

- 製造業の見積は、営業・技術・生産担当の連携が必要で、類似図面・過去見積・原価情報を探す時間が回答速度を左右する。
- 経産省のAI導入ガイドブックは、加工図面のAI自動見積における見積業務の属人化を課題としている。
- 中小機構・経産省資料では、ベテランの暗黙知、図面、手順、過去トラブルを見える化・検索可能にする方向が示される。

コピー候補：

1. 「見積依頼が来た。類似図面を探して30分。まだ見つからない。」
2. 「工場長が不在の日は、見積の返事が翌日になる。」
3. 「去年の似た案件が、ファイル名だけでは出てこない。」
4. 「若手の見積が、ベテランの席で止まっている。」

根拠：[中小機構・製造業の省人化](https://www.smrj.go.jp/institute/tokyo/training/sme/2026/TO266017.html)、[中小機構・技能伝承資料](https://www.smrj.go.jp/institute/tokyo/training/sme/2026/fqlu4c00000028m4-att/fqlu4c00000028ti.pdf)

### 運送・物流

- 国交省の2026年調査では、1運行あたりの荷待ち・荷役等時間は平均2時間2分。
- 中小事業者では乗務記録の電子化がまだ少なく、紙ベースの労務管理に時間と労力がかかっている。
- DX事例では、配車・受付・バース・点検記録をつなぎ、担当者の土地勘や経験への依存を減らす改善が扱われている。

コピー候補：

1. 「朝6時。配車変更が3件。どの車に反映したか追えない。」
2. 「ドライバーは倉庫で2時間待ち。事務所は電話で確認中。」
3. 「配車担当が休むと、変更理由を誰も説明できない。」
4. 「紙の点検表を、帰庫後にExcelへ打ち直している。」

根拠：[国交省・物流DX事例集](https://www.mlit.go.jp/seisakutokatsu/freight/content/001609016.pdf)、[国交省・物流の2024年問題](https://www.mlit.go.jp/report/press/tokatsu01_hh_000687.html)

### 旅館・ホテル

- 中国地方の宿泊施設調査では、67%が人手不足を感じている。
- 観光庁は、フロント業務・館内情報表示・自動チェックインなど、限られた人員で定型業務を回す省人化事例を支援している。
- 施設内情報表示の事例では、紙冊子の情報更新に全室分の作業時間と人的コストがかかっていた。
- ファーストビューでは「おもてなしをAIに任せる」ではなく、接客中・夜間の定型質問による中断を切り出す。

コピー候補：

1. 「チェックインの列に3組。代表電話が鳴る。」
2. 「22:40。『大浴場は何時まで？』の内線が入る。」
3. 「館内案内が変わった。全室の紙冊子がまだ差し替わっていない。」
4. 「朝食会場の案内を、同じフロントが何度も説明している。」

根拠：[中国運輸局・宿泊業の人手不足](https://wwwtb.mlit.go.jp/chugoku/00001_01967.html)、[観光庁・宿泊業の省人化事例](https://www.mlit.go.jp/kankocho/topics06_00032.html)
