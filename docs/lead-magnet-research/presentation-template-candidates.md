## AI顧問室向けの採用方針

### 第一候補: Canva + SlideModel / Slideworksの構造を組み合わせる

Canvaは表紙・写真・物体感・章扉を探すのに強く、SlideModelやSlideworksは「課題→分析→解決策→ロードマップ→リスク」の図解パターンが強いです。1つのテンプレを111枚に引き伸ばすのではなく、役割ごとに次の5系統をつくるのがよさそうです。

1. **Hero / Chapter**: 写真、人物、抽象オブジェクト、大きな数字
2. **Explain**: たとえ、用語、Before / After、1メッセージ
3. **Visualize**: フロー、マトリクス、タイムライン、分岐、レイヤー
4. **Do**: ワークシート、記入欄、コピペ用プロンプト、チェックリスト
5. **Offer**: 特典の物撮り、ブックローンチ、無料顧問CTA

### 今回の再設計で変えること

- タイトル位置を毎回同じにしない。表紙、全画面、左右非対称、中央配置、縦組み風の章扉を混ぜる。
- 文章だけのスライドを減らし、少なくとも各章に写真／イラスト／フロー／比較／ワークを配置する。
- 用語解説はカードの羅列ではなく、「たとえ → 定義 → 実務の1例」を1枚の図解にする。
- プロンプトは長文の枠ではなく、入力欄・変数・出力例・確認ポイントが見える作業シートにする。
- CTAはボタンだけにせず、10大特典を冊子・カード・ワークブックとして物体化する。

## ライセンス・取得メモ

- Canva、Pitch、Beautiful.ai、Gammaは、サービス内で使う場合とPPTXへ出力する場合で編集性・ライセンス・再利用条件が異なるため、採用前に個別確認する。
- SlideModel、Slideworks、Envatoは有料ライセンス前提の候補。購入せずに素材をコピーせず、今回はデザインの構造・見せ方の研究用として扱う。
- 既存テンプレの文章・画像・ロゴ・アイコンをそのまま教材へ転載しない。AI顧問室用の配色、図解、写真、コピーへ置き換える。
