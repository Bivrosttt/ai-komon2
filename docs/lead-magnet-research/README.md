# 海外AIコンサル／AI企業のリードマグネット調査

調査日: 2026-07-26

AI顧問室の相談後送付教材を設計するため、海外のAIコンサル企業とAI関連企業の配布形式・導線・教材化ポイントを比較したDBです。今回の主な発見は、コンサル企業では「診断結果そのもの」が入口になり、レポートを会話の起点にしていることです。

## コンサル型に共通する設計

1. 相談前に、無料診断や自己評価で「自社の現在地」を言語化する。
2. 診断結果は、点数だけで終わらせず、レーダー・ギャップ・優先順位で見せる。
3. 次に何をするかを、90日や最初の1業務など、実行単位へ落とす。
4. レポートやプレイブックを、役員説明・社内共有に使える体裁にする。
5. 最後に専門家相談を置くが、売り込みではなく、結果の読み解きとして提案する。
