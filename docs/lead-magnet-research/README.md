# 海外AI企業リードマグネット調査

調査日: 2026-07-26

AI顧問室の相談後送付教材を設計するため、海外AI関連企業10社の配布形式・導線・教材化ポイントを比較したDBです。

第三者資料の本文・PDFは公開サイトへ転載しません。直接配布されているPDFは、研究用にGit管理外の `research/lead-magnets/downloads/` へ保存しています。詳細な取得状況は同ディレクトリの `lead-magnets.json` を参照してください。

## 10社比較

| 企業 | 代表的なリードマグネット | 形式 | 導線の特徴 | AI顧問室での応用 |
| --- | --- | --- | --- | --- |
| Microsoft | Copilot Success Kit / Applying AI at Scale | 導入キット、チェックリスト、PDF | 導入フェーズ・役割別に分解し、顧客事例と導入支援へ接続 | 相談後に「準備・試行・定着」セットを送付 |
| Salesforce | AI Agents導入ガイド / SMB AI Guide | Ebook、PDF、実装フレーム | 小規模企業向けの導入手順を具体化し、Agentforce相談へ接続 | 業務別のAIエージェント候補診断 |
| HubSpot | Generative AI Ebook / State of AI / 無料診断ツール | フォーム付きEbook、レポート、無料ツール | リソースライブラリからCRM・相談・無料ツールへ連続導線 | 10特典を用途別に整理し相談後におすすめ順で送付 |
| Adobe | Firefly Product Guide | PDF製品ガイド | 機能ではなく企業導入の安全性・制作量・運用不安を解消 | AI導入リスク診断と社内ルール案をセット化 |
| Anthropic | Claude Skills Guide / Claude Code社内活用資料 | PDFハンドブック、技術プレイブック | Skill設計、テスト、配布、チーム運用まで教材化 | Claude Code実務教科書を顧客環境向けに編集 |
| OpenAI | How OpenAI Uses Codex / Codex Academy | PDF、フォロー教材、講座 | 実務プロンプト、デモ、開発者資料を学習導線に束ねる | Codex教科書に確認・テスト・レビューの型を追加 |
| Zapier | AI quick start / Guided templates / Agent templates | ガイド、ワークフロー、エージェントテンプレ | 読むだけでなくテンプレをコピーして自社環境で実行 | 入力・判定・通知まで含む業務フローを送付 |
| Intercom | Fin AI Agent collection | ナレッジベース、導入ガイド、ユースケース | チャネル・既存ヘルプデスク別に不安を解消し製品へ接続 | 顧客対応・営業・管理の業務マップを送付 |
| Gamma | AI Ebook Builder / AI slides resources | インタラクティブガイド、ツール、テンプレ | 解説から生成・共有・PDF/PPTX出力まで体験を直結 | AIスライド作成を構成・素材・レビュー・出力で教材化 |
| Canva | AI Presentation Maker / Magic Design | How-to記事、インタラクティブツール | 短い手順から生成・ブランド適用・編集・共有へ誘導 | 顧客の既存テンプレートで1枚作る実践課題を送付 |
