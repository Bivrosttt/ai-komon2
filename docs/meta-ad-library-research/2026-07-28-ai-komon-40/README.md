# AI顧問室 Meta広告・競合LPリサーチ（2026-07-28）

## 概要

Meta広告ライブラリで、AI顧問室の広告・LP改善に近い検索語を使って、掲載中の広告を40件収集した。広告ID、広告主、掲載開始日、広告コピー、CTA、遷移先LPを保存し、コピーとファーストビューの比較に使えるようにした。

- 取得日：2026-07-28（日本、掲載中広告）
- 検索語：`AI 顧問`、`AI コンサル`、`AI 導入 支援`、`生成AI 業務改善`、`AI 活用 診断`、`生成AI 中小企業`
- 件数：40広告
- 広告主：28
- ユニークLP：32
- 保存先：`records.csv`、`records.json`、`output/pdf/ai-komon-competitive-lp-research-2026-07-28.pdf`

### LP画面キャプチャ（追加済み）

32ユニークLPを、1440×900の固定ビューポートで上から順にスクロールし、1画面ごとにPNG保存した。各LPについて、PNGをそのままページ化したLP別PDFも生成している。

- 画面キャプチャ：`output/lp-screens/<LP slug>/screen-001.png` 以降
- LP別PDF：`output/lp-pdfs/<LP slug>.pdf`
- キャプチャ一覧：`output/lp-capture-index.json`、`output/lp-capture-index.csv`
- 完了：32/32 LP、合計316画面
- `records.csv` と `records.json` の各行に、PDFパス・画面数・ページタイトル・キャプチャ状態を追記済み

PDFの1ページが、ブラウザの1画面に対応する。固定ヘッダーや画面端の装飾も含め、キャプチャ時点の表示を保存している。

## 使い方

### DB

`records.csv` はスプレッドシートにそのまま読み込める形式。`records.json` は後でローカル分析・分類・LP比較に使う機械可読形式。

主な列は以下のとおり。

- `ad_library_id`：Meta広告ライブラリの広告ID
- `advertiser`：広告主名
- `started_running`：掲載開始日
- `ad_copy`：広告本文。前置き・改行を含む場合がある
- `cta`：Meta上のCTAラベル
- `landing_page_url`：`fbclid`等を落とした正規化LP URL
- `ad_library_url`：広告を再確認するための直接リンク
- `first_view_status`：今回のファーストビュー確認状態

### PDF

PDFには、調査目的・制約・ファーストビューの確認サンプル・40件の一覧をまとめている。まず広告コピーとLPの約束が一致している広告を優先して開き、次に以下を比較する。

1. ファーストビューの一文が誰のどの課題に刺さるか
2. CTAが無料診断・無料相談・資料DLなど、どれだけ低摩擦か
3. 数字、実績、対象者限定、助成金などの証拠があるか
4. 広告の訴求とLPのH1・CTAが一致しているか
5. AI顧問室の診断LPへ転用できる構造か

## ファーストビューの確認範囲

40件を同一ブラウザ条件で一括レンダリングしたものではない。今回、代表サンプルとしてインターネット・アカデミーのLP（広告ID `2288547545231743`）を実際に開き、DOM上のH1、CTA、数字を確認した。残りは広告コピーと遷移先URLを保存しており、`first_view_status=not_rendered_batch` として区別している。

広告主のLPを追加で確認する場合は、`landing_page_url` を直接開いて、広告のファーストビューと以下を記録する。

- H1、サブコピー、最初のCTA
- 誰向けか（経営者、管理職、情シス、人事など）
- 課題の切り口（人手不足、定着しない、何から始めるか分からない等）
- 数字・実績・保証・助成金
- フォームまでの距離と入力項目

## Meta広告ライブラリの制約

Meta広告ライブラリは、広告の掲載状態・広告主・コピー・CTA・遷移先の調査には使えるが、通常の商用広告についてCV数、CPA、予算、インプレッション、クリック率を比較するDBではない。成果比較はAI顧問室側のMeta Ads Insights、GA4、スプレッドシートのUTMイベントを別途突き合わせる。

また、公式APIは一般の日本向け商用広告を網羅的に取得する用途ではなく、政治・社会問題広告や一部地域の広告に範囲が限定されるため、今回は広告ライブラリのUIで取得した。

## 注意事項

- 競合広告の画像・文章をそのまま再利用しない。内部の構成・訴求仮説の研究用。
- 「掲載中」は「成果が高い」という意味ではない。
- 取得時点のスナップショット。広告やLPの内容、URL、掲載状態は後から変わる。
- URLに含まれる広告クリック識別子や個人識別につながる値は保存せず、LP比較に必要な正規化URLだけをDBに残した。
