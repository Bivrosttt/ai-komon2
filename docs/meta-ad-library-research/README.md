# Meta Ad Library リサーチ

最終更新: 2026-07-28

## 目的

「AIコンサル」「AI導入」「AI研修」「AI顧問」など、広告経由のLPを作るための社内リサーチ記録です。保存しているのは、広告主の訴求・CTA・遷移先・掲載開始日・Meta Ad Libraryの広告IDと、画面から取得した参考素材です。

## 公式APIの可否

Meta Ad Library APIは存在しますが、日本の一般的な商用広告を横断検索する用途には使えません。公式APIの対象は、世界中の社会問題・選挙・政治広告（過去7年）と、EU/英国に配信された全広告（過去1年）です。日本向けの通常の「AIコンサル」「AI導入」広告は、公式のAd Library UIで検索・確認する運用になります。

- 公式API案内: https://www.facebook.com/ads/library/api/
- Ad Library UI: https://www.facebook.com/ads/library/
- Meta Help: https://www.facebook.com/help/259468828226154

## 保存物

- `records.csv`: 広告ID、広告主、検索語、掲載開始日、訴求要約、CTA、LP URL、Ad Library URL
- `assets/2026-07-28-ai-consulting/`: AIコンサルティング検索結果の画面から取得した参考画像20点と取得マニフェスト

画像は広告主ごとの正確な対応付けができるよう、今後カード単位で再取得した際に `ad_library_id` を付けて整理します。現時点では「構成・色・情報量・CTAの見せ方」を見るための参考素材です。

## 利用上の注意

保存素材は社内の競合・構成リサーチ専用です。広告主の画像、コピー、ロゴ、ブランド表現をそのまま再利用したり、AI顧問室の広告へ転用したりしません。実制作では、訴求構造だけを抽象化し、独自のコピー・画像・デザインに置き換えます。

掲載継続日数は「テスト・運用が続いている可能性」を示す参考値であり、CVRやCPA、予約数、勝ちクリエイティブを意味しません。Ad Libraryから広告主の内部成果は取得できません。

## 次回の調査手順

1. Ad Libraryで国を日本、ステータスを配信中、広告タイプをすべてにする。
2. `AI コンサル`、`AIコンサルティング`、`AI 導入`、`AI 研修 企業`、`AI 顧問`を別々に検索する。
3. 広告ID・開始日・コピー・CTA・LP URLを `records.csv` に追加する。
4. LPは「ファーストビューの約束」「対象者」「証拠」「不安解消」「CTA」「フォーム/予約導線」の順で比較する。
5. 成果は推測せず、掲載継続・複数クリエイティブ・LPの導線整合性を仮説の根拠として記録する。
