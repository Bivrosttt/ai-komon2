# AI顧問室のスキル入口

このリポジトリでSEO記事を作成・更新するときは、記事の種類に合わせて次のスキルを選びます。

## 比較記事を作るとき

**実在サービスの比較記事は、まず [noimos-comparison-article/SKILL.md](noimos-comparison-article/SKILL.md) を読む。**

このスキルが比較記事の手順とチェックリストの唯一の正本です。公式ホーム画面、公式価格・usage、国内外レビュー、コスパ、強み・弱み、初出公式リンク、記事末尾のAI顧問室CTA、レスポンシブ確認までを一つのチェックリストで管理します。

案件ごとの進捗チェックリスト（永続TODO）と調査証跡は、[`docs/noimos-organic-growth-skills/seo-articles/ai-service-comparisons/`](../docs/noimos-organic-growth-skills/seo-articles/ai-service-comparisons/) に置きます。入口からたどる場合は [SEO記事運用インデックス](../docs/noimos-organic-growth-skills/seo-articles/README.md) を開いてください。

## 一般的なSEO/GEO記事を作るとき

[noimos-seo-geo-article/SKILL.md](noimos-seo-geo-article/SKILL.md) を使います。比較対象が実在サービスの選定ではない記事は、こちらが基本です。

## 比較記事の最短手順

- [ ] 対象記事ごとの永続TODOを作る
- [ ] 比較ブリーフ、公式・国内外レビュー調査、claim ledger、価格/usage入力をそろえる
- [ ] 各サービスの公式ホーム画面を取得し、サービス節の先頭へ置く
- [ ] 価格・usage・コスパ表、強み・弱み表、用途別の第一候補と選ばない条件を書く
- [ ] 初出サービス名を公式ホームへリンクし、料金URLは価格ソースとして分離する
- [ ] 比較バリデータ、SEO/GEO validator、品質ゲート、実ブラウザ表示を確認する
- [ ] TODOの証跡を照合してから完了にする

チェックリストを別ファイルへ複製せず、必ずスキル本体と案件TODOを更新してください。これにより、ルールの二重管理を防ぎます。
