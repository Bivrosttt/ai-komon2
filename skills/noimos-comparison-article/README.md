# Noimos比較記事スキル

このディレクトリの正本は [`SKILL.md`](SKILL.md) です。比較記事の全工程は、同ファイル内のチェックリストに従って進めます。

- 実行ルール・禁止表現・必須成果物: [`SKILL.md`](SKILL.md)
- 公式情報・口コミ・価格の調査基準: [`references/research-evidence.md`](references/research-evidence.md)
- 自動検証: [`scripts/validate_comparison_article.py`](scripts/validate_comparison_article.py)
- スクリーンショット検証: `--screenshot-ledger` を渡すと、台帳の全画像が `visual_check: pass` かを自動検査（目視確認そのものは `view_image` 等で実行）
- 案件別TODOと調査証跡: [`docs/noimos-organic-growth-skills/seo-articles/ai-service-comparisons/`](../../docs/noimos-organic-growth-skills/seo-articles/ai-service-comparisons/)

案件を開始したら、対象記事専用の`*-TODO-YYYY-MM-DD.md`を作り、スキルの各項目を証跡付きでチェックしてください。別のチェックリストを作ってルールを複製する運用は禁止します。
